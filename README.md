# 🌸 IRIS Classifier API

An End-to-End MLOps project demonstrating the complete machine learning lifecycle from data preparation to model monitoring and deployment.

## 🎯 Project Goal

The goal of this project is to build a production-oriented machine learning system and demonstrate practical MLOps skills.

This project covers:

- Data management
- Data validation
- Model training
- Experiment tracking
- Model evaluation
- Model optimization
- Deployment workflow
- Monitoring

The project is designed as a portfolio project to demonstrate the ability to design and implement an end-to-end ML system.
